# 1차 피드백 정리 — 2026-10-04 회의 (28분, 3명)

> 원문 `docs/261004 뿌거 1차 피드백.txt`. 결론은 "루비(참석자 2)가 말한 대로 디벨롭". 아래는 발언을 항목으로 추리고 결정·검토·아이디어·확인으로 나눈 것이다. 번호는 우선순위가 아니라 식별용이다.

## A. 결정 — 그대로 반영한다

| # | 내용 | 비고 |
|---|---|---|
| A1 | **홈과 기록 탭을 합친다.** 지금 홈의 준 돈·받은 돈 총액을 **위에 한 줄**(모바일은 두 줄)로 작게 두고 바로 아래가 기록 목록. "기록 보기" 버튼은 없앤다 | 세 사람 모두 동의. 총액은 궁금하니 남기되 넓게 차지하지 않게 |
| A2 | **탭을 홈 · 내 행사 · 통계 · 더보기로 바꾼다.** "내 행사" 탭이 새로 생긴다 | 참석자 3 제안, 동의 |
| A3 | **내 행사 탭** — 결혼식·돌잔치·장례식 같은 내 행사 목록. 누르면 그 행사의 받은 돈이 나오고 **맨 위에 청첩장·부고장(발행)** 이 있다. 비어 있으면 가운데 "+ 만들기"로 유도 | 받은 돈의 "행사별 묶음(폴더)". 경쟁 앱의 폴더링 벤치마크 |
| A4 | **기록 화면의 "가져오기" 버튼을 뺀다.** 가져오기는 전체 파일을 넣는 것이라 더보기(또는 내 행사)에만 둔다 | 참석자 2 |
| A5 | **기록 입력에 경조사 종류(카테고리) 선택 칸** — 하나씩 입력할 때도 종류를 고른다 | 3은 "벌크 입력이 주라 안 쓸 것"이라 했지만 빠뜨린 것을 하나씩 넣는 경우가 있어 **있어야 한다**로 정리 |
| A6 | **경조사 종류에 '생일' 추가.** 생일 목록 관리가 아니라 생일에 주고받은 돈만 | 생일이 더 자주 오는 행사 |
| A7 | **삭제 버튼을 숨긴다.** 지금은 빨갛고 메인 자리라 "지우고 싶게 생겼다". ⋯(더보기) 메뉴 안으로 한 단계 넣고, 확인은 지금처럼 한 번 | 확인 창은 이미 있다. 문제는 노출과 색 |
| A8 | **앱 색·컨셉 재정비.** 지금 색이 컨셉과 안 맞는다 | 참석자 3. 구체 색은 미정 |
| A9 | **랜딩 제목을 '뿌린'으로** 짧게, 부제에 '뿌린대로거두리라' | 아이콘은 좋다는 반응 |
| A10 | **앱 잠금(암호·Face ID)** 옵션을 더보기에 | 금전 정보라 민감. iOS 는 시스템 잠금이 있지만 안드로이드까지 같이 제공 |

## B. 검토 — 설계가 필요하다
